Система учета товаров на складе

Добро пожаловать!

Это учебное веб приложение для учета товаров на складе разрабатываемое в рамках лабораторных работ по дисциплине "Разработка веб-приложений".

Архитектура приложения:

  • Фронтенд HTML, CSS, JavaScript, Bootstrap 5
  • Бекэнд Python3, Flask, REST API
  • Хранение JSON файлы (без базы данных)
  • Контроль версий Git, Github
