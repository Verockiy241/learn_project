# Лабораторная работа №2
## Разделение приложения на frontend- и backend-сервисы с использованием APIFlask и Flask

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Бэкенд** | Python 3, APIFlask | Серверная логика, API и автодокументация (Swagger) |
| **Фронтенд** | Python 3, Flask | Клиентское приложение и визуализация данных |
| **API** | RESTful API | Взаимодействие сервисов по протоколу HTTP |
| **Хранение** | JSON Файлы | Локальное хранение данных |
| **Контроль версий** | Git, GitHub | Управление исходным кодом |
