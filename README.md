# Лабораторная работа № 3
## Разработка двухсервисного веб-приложения FastAPI + Pydantic + Flask + SQLite

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Бэкенд** | Python, FastAPI, Pydantic | Серверная логика, бизнес-логика, предоставление REST API, валидация данных и автодокументация через Swagger. |
| **Фронтенд** | Python, Flask, HTML, CSS | Клиентское приложение без использования JavaScript, отображение HTML-страниц, рендеринг шаблонов и обработка HTML-форм. |
| **API** | REST API | Взаимодействие сервисов по протоколу HTTP (Flask вызывает методы FastAPI через библиотеку requests). |
| **Хранение** | SQLite | Локальное хранение данных в реляционной встроенной базе данных (сохраняется в одном файле). |
| **Контроль версий** | Git, GitHub | Управление исходным кодом. Работа ведется строго в ветке `lab03`. |
